# E-Commerce Sales & Customer Analytics

## Project Overview

This project uses SQL to analyze e-commerce sales, customer behavior, product performance, regional performance, discounts, and business trends.

The project contains 13 SQL scripts covering data cleaning, validation, business KPIs, customer analytics, and advanced SQL analysis.

## Project Objectives

- Clean and validate e-commerce data.
- Analyze overall sales and profitability.
- Identify product and customer performance trends.
- Evaluate regional and discount performance.
- Perform RFM, cohort, and ABC analysis.
- Investigate business problems using SQL.
